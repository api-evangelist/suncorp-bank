# Suncorp Bank

> Suncorp Bank is an Australian retail and business bank (Brisbane, Queensland), acquired by ANZ on 31 July 2024 and operating as an ANZ division under the Suncorp Bank brand during a multi-year transition. As a Consumer Data Right (CDR) data holder it exposes a public, unauthenticated Product Reference Data (PRD) API conforming to the Australian Consumer Data Standards, plus an accredited (FAPI-grade) consumer-data-sharing tier.

## APIs

- [Suncorp Bank CDR Product Reference Data API](https://www.suncorpbank.com.au/help-support/open-banking.html): Public, unauthenticated CDR PRD API exposing currently offered banking products. Base URL https://id-ob.suncorpbank.com.au/cds-au/v1. GET /banking/products and /banking/products/{productId}. Requires the x-v version header (currently x-v 5 for the product list).

## Specs

- [OpenAPI (CDR Banking API, shared DSB standard)](openapi/suncorp-bank-cds-banking-products-openapi.yml): DSB Consumer Data Standards CDR Banking API, OpenAPI 3.0.3 v1.36.0. Suncorp implements the two unauthenticated product operations.
- [OIDC discovery](well-known/suncorp-bank-openid-configuration.json): Live CDR/FAPI OpenID Connect configuration for the accredited data-sharing tier.
